# Concept 2 정면 캐비넷 · 절제된 깊이 연출

2026-09-28 · 사용자 요청: 스크롤 상세 사진을 루트 concept 2.png의 캐비넷으로 교체하고, 입체감을 더하되 조잡하지 않게 애니메이션 재구성.

## 범위

KCP 상세의 7단계 공정 사진·스크롤 연출만 변경한다. 메인 프로토타입과 승인된 KCP Hero는 유지한다. 기존 SEO 본문, 8개 목차 ID, 단계 링크, FAQ, 비활성 Free Quote, noindex, 회사 제공 사실을 보존한다.

## 디자인

- 원본의 정면 세이지/올리브 그레이지 셰이커 캐비넷, 대리석 아일랜드, 황동 펜던트 두 개, 라탄 스툴 세 개, 왼쪽 정원 창과 오른쪽 아치를 유지한다.
- 글자/UI가 없는 1536×1024 사진 master에서 기존 크림색 도장, 선택 도어가 없는 상태, 완성 상태를 파생한다. 작업장 마감도 같은 세이지 색상으로 맞춘다.
- 큰 유령 숫자·격자·떠 있는 기술 주석을 제거하고 작은 단계 번호·진행·이동 컨트롤만 남긴다.
- 분리된 사진 도어는 같은 원근 기준에서 앞으로 이동한다. 좌우 이동 최대5%, 깊이 최대120px, Y축 회전 최대12도, X축 최대3도, Z축 최대1.5도로 제한한다. 순차 easing과 깊이에 비례하는 부드러운 그림자로 부품 간 차이를 만든다.
- 캐비넷을 CSS 도형으로 새로 그리지 않는다. 실제 사진의 선택 도어 영역을 잘라 표시하고 3D transform을 적용하는 방식이다. 실제 3D CAD·WebGL 모델 또는 문짝 뒷면 전체를 재현한 모델이라고 주장하지 않는다.
- 펜던트 뒤의 문짝은 원본 사진에서 가려져 있으므로 독립 이동 대상으로 삼지 않는다. 후드 왼쪽 작은 도어, 오른쪽 벽장 두 도어, 키 큰 캐비넷의 큰 전면 세 개를 선택한다. 가려진 부품을 억지로 움직여 조명 조각이 따라오는 현상을 피한다.
- 손잡이는 해당 도어 사진에 포함된다. 힌지와 손잡이 독립 분리의 기존 TODO는 유지한다.
- 도장 장면은 동일 작업장 문짝 위로 부드럽게 마감 상태가 바뀌고, 5단계 안에서 Finish01/02로 진행한다.

## 기술·재사용

공용 RegisteredLayer에 깊이·축별 회전·stagger를 추가한다. 콘텐츠 모듈이 사진·선택 영역·움직임 값을 공급하며 공용 controller는 회사/캐비넷 내용을 알지 않는다. 기존 읽던 위치 복원, 정적 보기, 근처 자산 preload를 보존한다.

고정 배경은 원래 master 사진을 그대로 유지한다. 별도 생성한 열린 캐비넷 내부는 6개 고정 마스크 안에서만 보여 주고, 같은 master에서 잘라낸 문짝을 그 위에서 움직인다. 생성 편집 과정에서 벽·손잡이·가구 위치가 조금 달라져도 고정 실내가 흔들리지 않도록 구성했다.

원근은 공통 부모에 적용하고 이동/그림자 wrapper와 사진 clip을 분리한다. 중첩 3D의 평면화 조건은 [MDN perspective](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/perspective), [transform-style](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transform-style)을 확인했다. 구현 결과는 브라우저에서 별도 판정한다.
